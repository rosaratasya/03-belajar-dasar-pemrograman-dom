\# Catatan 3.10 JavaScript



\## Yang Dipelajari



\- Variabel menggunakan `let` dan `const`.

\- Tipe data string, number, dan boolean.

\- Percabangan menggunakan `if`.

\- Function untuk menentukan kategori nilai.

\- Array berisi object.

\- Perulangan menggunakan `for...of`.

\- Menghitung jumlah data yang belum selesai.
