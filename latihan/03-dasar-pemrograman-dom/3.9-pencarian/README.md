# Pencarian Barang

Program ini digunakan untuk mencari barang berdasarkan nama.

## Data Demonstrasi

| Nama | Kategori |
|---|---|
| Buku | Alat Tulis |
| Pensil | Alat Tulis |
| Penghapus | Alat Tulis |
| Penggaris | Alat Tulis |
| Tas | Perlengkapan |

## Fitur

- Pencarian barang berdasarkan nama.
- Tidak membedakan huruf besar dan kecil.
- Menampilkan kategori barang.
- Menolak input kosong.
- Menampilkan pesan jika barang tidak ditemukan.
