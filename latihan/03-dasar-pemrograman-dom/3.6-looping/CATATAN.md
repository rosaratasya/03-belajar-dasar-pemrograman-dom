\# Catatan 3.6 Looping



\## Hasil latihan

\- Loop 3 kali menghasilkan Barang ke-1 sampai Barang ke-3.

\- Batas 1 menghasilkan Barang ke-1.

\- Batas 0 tidak menghasilkan output.

\- Total Rp3.000 x 3 = Rp9.000.

\- Total dengan pengulangan 0 = Rp0.

\- Modifikasi Rp5.000 x 3 = Rp15.000.



\## Tugas mandiri

\- 5 pensil x Rp2.000 = Rp10.000.

\- 1 pensil x Rp2.000 = Rp2.000.

\- 0 pensil = Rp0.
