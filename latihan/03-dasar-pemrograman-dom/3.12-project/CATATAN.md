\# Catatan 3.12 Project



\## Fitur



\- Pencarian barang berdasarkan nama.

\- Pencarian tidak membedakan huruf besar dan kecil.

\- Menampilkan nama dan kategori barang.

\- Menolak input kosong.

\- Menampilkan pesan jika barang tidak ditemukan.

\- Menggunakan data barang lokal.

\- Menggunakan DOM dan event JavaScript.

\- Menggunakan HTML dan CSS.



\## Data Demonstrasi



| Nama | Kategori |

|---|---|

| Buku | Alat Tulis |

| Pensil | Alat Tulis |

| Penghapus | Alat Tulis |

| Penggaris | Alat Tulis |

| Tas | Perlengkapan |



\## Hasil Pengujian



\- Pencarian `Pensil` → berhasil.

\- Input kosong → berhasil ditolak.

\- Pencarian `Sepatu` → berhasil menampilkan pesan tidak ditemukan.
