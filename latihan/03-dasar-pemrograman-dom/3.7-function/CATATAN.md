\# Catatan 3.7 Function



\## Hasil latihan

\- Function totalBelanja(12000, 2) menghasilkan 24000.

\- Data Buku dengan harga 5000 dan jumlah 2 menghasilkan 10000.

\- Data Pensil dengan harga 2000 dan jumlah 3 menghasilkan 6000.



\## Tugas mandiri

Function menerima nama barang, harga, dan jumlah.

Function menghitung total dengan rumus harga x jumlah.
